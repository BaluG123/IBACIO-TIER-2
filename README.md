# IB ACIO Tier-2

React Native exam-prep app for **Intelligence Bureau ACIO Grade-II/Executive Tier-2** (descriptive paper: Essay + English Comprehension + 2 Long Answers · 50 marks · 60 minutes).

Made with ❤️ for aspirants who cleared Tier-1 and need writing practice.

## Quick start

```bash
npm install
npm start
npm run android   # or: npm run ios
```

## Features

- Essay topics with hints, timers, drafts, model outlines, self-check
- Comprehension passages with descriptive model answers
- Long-answer drills (Current Affairs / Economics / Socio-political)
- **Daily Writing Desk** — OTA from GitHub (offline fallback bundled)
- Full 60-minute descriptive mocks + self-score history
- Model answers & examiner tips
- Previous year papers (WebView)
- English / Hindi UI
